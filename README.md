# Hiromu Otsubo — Portfolio

Personal portfolio and the interactive WebGL work **Journey**.

Journey is an interactive landscape inspired by Kamikochi. It combines a
Blender-built 3D environment with watercolor-like rendering, mist, light,
spatial sound, scrolling, and hold interactions.

## Pages

- `/` — Portfolio home
- `/journey` — Interactive Journey experience
- `/about` — Profile, research, approach, and motivation
- `/project` — Journey case study
- `/contact` — Contact

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The production site is deployed to Vercel from a private GitHub repository.
